# 33.1 – Checklist de nettoyage des données – DataFrame `df`

**Base :** DataFrame pandas nommé `df`
**Objectif :** garantir la fiabilité, la cohérence et la reproductibilité des données avant toute analyse.

---

## 33.1.1 – Exploration et visualisation des données (`df`)

- [ ] **Charger / importer** le jeu de données dans le DataFrame `df`
- [ ] **Visualiser** : `df.info()` – types de colonnes et types non nulles
- [ ] **Visualiser** : `df.head()` / `df.tail()` – premières / dernières lignes
- [ ] **Visualiser** : `df.shape` – dimensions (lignes, colonnes)
- [ ] **Visualiser** : `df.columns` – liste des colonnes
- [ ] **Visualiser** : `df.describe()` / statistiques descriptives (numériques)
- [ ] **Visualiser** : `df.isnull().sum()` – quantité de valeurs manquantes par colonne
- [ ] **Visualiser** : `df.duplicated().sum()` – détection des doublons
- [ ] **Documenter** : synthèse des observations pré-nettoyage

## 33.1.2 – Traitement des doublons

- [ ] **Définir** les colonnes clés de déduplication (ex. : id, couple de colonnes)
- [ ] **Détecter** les doublons via `df.duplicated(subset=…)`
- [ ] **Décider** du traitement (suppression / consolidation)
- [ ] **Supprimer** les doublons : `df = df.drop_duplicates(subset=…)`
- [ ] **Vérifier** : nouveau `df.duplicated().sum()` == 0

## 33.1.3 – Vérification et correction des formats

- [ ] **Vérifier** les types de données (int, float, str / object, bool, datetime)
- [ ] **Convertir** les colonnes en `datetime` si nécessaire (`pd.to_datetime`)
- [ ] **Normaliser** les formats de dates (ISO / fr-FR / avec ou sans heure)
- [ ] **Nettoyer** les formats numériques (virgule décimale → point, %, pourcentages)
- [ ] **Normaliser** les chaînes de caractères (espaces superflus, casse, encodage)
- [ ] **Adapter** les types avant toute agrégation ou analyse

## 33.1.4 – Gestion des valeurs manquantes

- [ ] **Identifier** les colonnes / lignes concernées
- [ ] **Décider** des stratégies : suppression de ligne, suppression de colonne, remplissage (moyenne / médiane / mode / valeur cible / interpolation)
- [ ] **Appliquer** la stratégie choisie
- [ ] **Vérifier** : plus de valeurs manquantes (ou justification)

## 33.1.5 – Gestion des valeurs aberrantes / outliers

- [ ] **Détecter** les outliers (IQR / z-score / seuils métier)
- [ ] **Décider** : conserver / corriger / supprimer
- [ ] **Documenter** les décisions prises

## 33.1.6 – Cohérence, sauvegarde et validation finale

- [ ] **Ré-exécuter** l’exploration rapide (info / head / shape / nulls)
- [ ] **Valider** les colonnes transformées
- [ ] **Sauvegarder** le DataFrame nettoyé (`df_clean`) ou l’export correspondant
- [ ] **Journaliser** les transformations appliquées
